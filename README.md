# 唐宋山河图

以 618—1279 年为时间轴，浏览山河、历史事件、诗人的行迹与作品。

打开 `index.html` 对应的网址即可使用。支持缩放和平移地图、进入城池示意、切换或播放年代、查看人物年龄与本年此地的作品。

地图为风格化的历史概略示意，城市位置及城池布局不代表精确复原。人物行迹存在空白年份；部分作品的创作时间与地点尚有异说。

## GitHub Pages

本仓库已包含完整站点文件，无需安装依赖或运行构建。将仓库推送到 GitHub 后，在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。`Deploy Pages` 工作流会发布已提交的站点；可通过 Actions 手动触发。

也可以选择从 `master` 分支的 `/ (root)` 发布。资源均使用相对路径，支持仓库子路径访问。`index.html` 是唯一首页。
